LYRICS FOR SOUNDCLOUD

Настройки

Расширение работает локально в Chrome. Ключи сохраняются в профиле браузера и отправляются только соответствующему API.

Поведение

Построчная синхронизация включается автоматически, когда для песни найдены точные временные метки.

Musixmatch API

Необязательно. Используется первым для поиска официальных построчных временных меток. Если совпадения нет, расширение автоматически продолжит поиск в LRCLIB и Genius.

Genius API

Необязательно. Если обычный поиск Genius блокируется, вставьте Client Access Token своего приложения Genius.
